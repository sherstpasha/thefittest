Multiobjective utilities

Sorting and dominance comparisons expect maximization fitness. Negate columns that should be minimized before calling them directly. Crowding distance accepts either objective direction but must be evaluated within one front.

The convergence metric measures obtained-to-reference distances (not IGD). The diversity metric measures two-objective spread for minimization fronts. Neither metric normalizes objective units.

Utilities for optimization with multiple objectives.

thefittest.utils.multiobjective.compare_rank_and_crowding(rank_i: int, distance_i: float, rank_j: int, distance_j: float) → int

Compare two solutions using precomputed NSGA-II metadata.

Return 1 if solution i is better, -1 if solution j is better, or 0 for a tie. Lower nondomination ranks are preferred. For equal ranks, larger crowding distances are preferred. Distances may include positive infinity, but must not contain NaN. No objectives are evaluated here.

thefittest.utils.multiobjective.compare_dominance_and_crowding(fitness_i: ndarray[tuple[Any, ...], dtype[float64]], distance_i: float, fitness_j: ndarray[tuple[Any, ...], dtype[float64]], distance_j: float) → int

Compare by direct dominance, then crowding distance.

Return 1 if i wins, -1 if j wins, and 0 for a tie. All objectives are maximized, as in fast_non_dominated_sort. Objective vectors must have the same positive length and contain no NaN. If neither solution dominates the other (including equal vectors), prefer the greater crowding distance, regardless of nondomination rank.

thefittest.utils.multiobjective.fast_non_dominated_sort(fitness: ndarray[tuple[Any, ...], dtype[float64]]) → ndarray[tuple[Any, ...], dtype[int64]]

Assign nondomination ranks to rows of a fitness matrix.

Parameters:
fitnessNDArray[np.float64]

Matrix of shape (n_individuals, n_objectives). All objectives are maximized, following the library’s internal fitness convention. Negate objectives that should be minimized before calling this function. At least one objective is required. NaN values are not supported.

Returns:
NDArray[np.int64]

Rank of each individual in the original row order. Rank 1 denotes the first nondominated front; lower ranks are better. Equal fitness vectors do not dominate one another. An empty population returns an empty rank array.

Notes

Implements the fast nondominated sorting procedure of Deb et al. (2002), NSGA-II, comparing each unordered pair only once. A solution dominates another if it is no worse in every objective and strictly better in at least one. The dominated sets are stored as a boolean adjacency matrix. Time complexity is O(M * N**2), and auxiliary space is O(N**2), where N is the number of individuals and M is the number of objectives. The input is not modified. The first call compiles the Numba kernel.

References

[1]

Deb, K. et al. (2002). A fast and elitist multiobjective genetic algorithm: NSGA-II. IEEE Transactions on Evolutionary Computation, 6(2), 182-197. doi:10.1109/4235.996017.

Examples

>>> fitness = np.array([[3., 1.], [1., 3.], [1., 1.], [0., 0.]])
>>> ranks = fast_non_dominated_sort(fitness)
>>> ranks
array([1, 1, 2, 3])
>>> np.flatnonzero(ranks == 1)
array([0, 1])
thefittest.utils.multiobjective.crowding_distance_assignment(fitness: ndarray[tuple[Any, ...], dtype[float64]]) → ndarray[tuple[Any, ...], dtype[float64]]

Compute NSGA-II crowding distances within a single front.

Parameters:
fitnessNDArray[np.float64]

Finite objective values of one front, with shape (n_individuals, n_objectives). At least one objective is required. Values may be supplied in their original minimization or maximization convention. Front membership must be determined by the caller.

Returns:
NDArray[np.float64]

Distances in the original row order. Larger distances favor less crowded solutions. Boundary solutions receive infinity. Fronts of one or two individuals receive infinity for every member; an empty front returns an empty array.

Notes

Each objective requires its own ordering. Stable mergesort preserves the previous objective’s ordering for ties, matching successive Python list.sort calls. Neither the input values nor their row order is modified. Constant objectives contribute nothing and do not assign boundaries. Consequently, an entirely constant front with more than two members has zero distances. This explicitly handles the zero denominator left undefined by the original NSGA-II pseudocode.

Time complexity is O(M * L * log(L)), with O(L) auxiliary space for a front of L individuals and M objectives. Compilation occurs on first use.

Examples

>>> front = np.array([[0., 3.], [1., 2.], [2., 1.], [3., 0.]])
>>> crowding_distance_assignment(front)
array([       inf, 1.33333333, 1.33333333,        inf])
thefittest.utils.multiobjective.convergence_metric(front: ndarray[tuple[Any, ...], dtype[float64]], reference_front: ndarray[tuple[Any, ...], dtype[float64]]) → float

Deb et al. (2002) convergence metric gamma in original objective units.

Average the distance from each obtained solution to its nearest reference point. This is the opposite direction from IGD. The paper uses 500 reference points uniformly spaced in objective space. Empty obtained fronts have infinite distance; the reference must be nonempty.

thefittest.utils.multiobjective.diversity_metric(front: ndarray[tuple[Any, ...], dtype[float64]], reference_front: ndarray[tuple[Any, ...], dtype[float64]]) → float

Two-objective spread delta, equation (1) of Deb et al. (2002).

Inputs are minimization fronts in original objective units. Consecutive distances use ascending first-objective order, retaining duplicate points. Endpoint distances are measured to the reference front’s two extremes. Thus endpoint estimation uses the supplied reference rather than fitting a parallel curve to the obtained front. A front with fewer than two solutions receives 1.0. No objective normalization is applied.
